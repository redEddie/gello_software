## 2. 상세 내역

<a id="d-scene-core"></a>
### scene-v1 저장 계층

파일 = scene (`scene_NNN.hdf5`). `metadata` 그룹(scene_id·objects·3×3
layout·description·next_episode_idx·기준사진)과 루트 `episode_NNN` 그룹으로
구성. 에피소드 attrs 에 instruction·episode_uid(`EP-S000-I000-E000`)·
quality_status·collector 등. 재판정(success↔failed)이 1차 큐레이션이고,
8/14 밤부터 **삭제·트림도 허용**(아래 [→](#d-edit)). 상세 스키마는
`docs/scene-collection-handoff.md` §2.

<a id="d-phases"></a>
### Phase 1~3 + legacy UI 제거

워커가 SceneWriter 로 저장(Null/Scene/Legacy 3분기), 변환기가 양포맷을 읽고
`meta/episode_uids.json` 사이드카(uid·scene·slot·품질)를 남긴다. GUI 는
scene 수집이 유일한 방식이 됐다(legacy 는 관리·변환만 유지). 기준 사진은 첫
에피소드 기록 시작 때 agentview 프레임 자동 캡처.

<a id="d-ids"></a>
### ID 체계 (8/13 확정, 데이터 규약)

- **instruction_id 는 scene 로컬**: 모든 scene 은 I000 부터, 새 문장마다 +1.
- **episode_uid 의 E번호는 slot 로컬**: 각 (scene, instruction) 은 E000 부터.
- 파일 그룹명 `episode_NNN` 은 파일 전역 추가 순서. slot 전역 식별은
  (scene_id, instruction_id) 쌍. scene 간 "같은 문장"은 텍스트로 파생.

<a id="d-plan"></a>
### 수집 계획 (pilot.json 체계)

`configs/collection_plans/*.json` = scene × instruction × target 목표.
카운트는 항상 scene 파일에서 계산(두 개의 진실 금지).

- **선택**: Configure "수집 계획" 콤보. `+` 새 계획(이름→빈 파일→편집),
  `🗑` 삭제, `✎` 편집.
- **편집 폼**: scene 별 표에서 문장·목표만 수정. ID 는 자동(기존 행 번호
  유지, 새 행은 다음 번호, 지운 번호 재사용 금지 — 수집된 데이터와의 연결
  보호). 행 이동 ▲▼, scene 추가/삭제, 문장 중복 즉시 표시, 저장 시
  load_plan 규칙 검증. 고급은 "JSON 직접 편집".
- **잠금**: 계획이 선택돼 있으면 시작 문장(Configure)과 세션 중
  slot(Collect)은 **드롭다운에서만** 고른다(자유 입력이 계획 밖 slot 을
  만든 실사고 재발 방지, 연결·적용 시점 이중 검증). 자유 수집은
  "(계획 없음)" 선택.
- **진행률**: Statistics "수집 계획 진행률" — scene×slot 수집/목표 표 + 전체 %.
  파일 없는 scene 은 표에서 빼고 하단 요약에만 표기.

<a id="d-gate"></a>
### 게이트·리셋 안전화

- 자동 정렬이 켜져 있어도 리더가 GATE_RAD(0.5rad) 밖이면 당기지 않고
  안내 후 대기. 범위 진입 첫 순간 1회 발동.
- Start 버튼·툴바 Record·Space 는 자세가 맞아야만 활성 (워커 거부는 백스톱).
- 리셋 대기 중에도 카메라 라이브 뷰 유지 (물체 되돌리는 시간이 화면을 가장
  많이 보는 시간).

<a id="d-grid"></a>
### 3×3 워크스페이스 격자

작업면 꼭짓점 4개(정규화 좌표)로 정의, 내부 선은 원근 변환. 편집기(Live 탭
"격자 편집..."/Layout 페이지): 드래그, 상하좌우 정렬, "변환"으로 내부선 재계산,
실행취소 20단계, 이름 저장/불러오기, **크롭 가이드 체크박스**(변환 후 남는
정사각 표시). Live 오버레이: 체크박스+투명도, agent 뷰 전용, **저장 데이터에는
안 들어감**. 저장: `~/libero_gui_logs/workspace_grids.json`.

<a id="d-dataset"></a>
### Dataset·갤러리·배치도

- Dataset 페이지: scene 파일 표시, 폴더 선택, 재판정(성공↔실패), scene

  불변 규약이라 차단 안내).
- Gallery 탭: uid 기반 썸네일 캐시, 필터, 더블클릭 재생, 재판정.
- 오른쪽 패널 "Scene 배치 (수집 중)": 세션 scene 의 3×3 배치도를 상시 표시.

<a id="d-replay"></a>
### 실로봇 재생

`experiments/replay_episode.py`: 기록된 `commanded_joint_states` 를 같은
주기로 재전송(양포맷). 램프→Enter 확인→틱당 클램프, `--speed 0.1~1.0`,

배속 입력→경고 확인→실행, **재생 중에는 버튼이 "■ 재생 중단"으로 토글**

<a id="d-h5view"></a>
### HDF5 트리 뷰어

Dataset "HDF5 트리 뷰어": 그룹/데이터셋 트리(shape·dtype·압축) + **attrs 를
`@이름 값` 기울임꼴 항목으로 트리에 직접 표시**(metadata 맨 위) — myHDF5 가
attrs 를 오른쪽 패널에만 보여줘 생긴 "필드가 없다" 오해 해소. 클릭 시 전체
값·이미지 미리보기·depth 컬러맵 미리보기. "myHDF5 (웹)" 버튼은 브라우저 연결.
파일은 열 때만 읽고 쥐지 않는다.

<a id="d-diversity"></a>
### scene 다양성 추천 (#33 완결)

거리 [0,1] = 물체 조합(Jaccard) 0.5 + 배치(존 맨해튼) 0.35 + 관계 0.15.
farthest-point sampling 으로 기존 scene 들과 가장 먼 3안(제약: 컵≥1+다른
종류≥1, 물체 2~5, 존 비충돌; seed 결정적). CLI `scripts/recommend_scene.py`
(+`--selftest`), GUI 는 "새 Scene 구성 → 추천 받기..." — 고르면 체크·배치
자동 채움.

<a id="d-depth"></a>
### depth 계열 (#17 + Depth/Point Cloud 탭)

- **기록(#17)**: Settings → "데이터셋 구조 사용자 설정" 의 체크박스 2개
  (Agentview/Eye-in-hand depth). uint16 mm + lzf 무손실 + **원본 해상도**
  (RGB 크롭/리사이즈 비적용 — 원시 저장 + 후처리 원칙). 기본 꺼짐(캠당
  USB +~176Mbps). 변환기는 소비 키만 비교하므로 depth 유무가 섞여도 변환
  가능(LeRobot 변환은 depth 무시).
- **Depth 탭**: 컬러맵 라이브 뷰(가까움=빨강) + **오른쪽 척도 바** + 최대
  거리 슬라이더 + **마우스 커서 지점 실거리 표시**. Agent/Wrist 선택.
- **Point Cloud 탭**: 역투영 포인트클라우드, 회전/기울임 슬라이더.
- **안정성 원칙**: 두 탭 중 하나가 보일 때만 depth 스트림이 켜지고(RGB
  미리보기 잠시 내림/복원), **계산도 보이는 탭 것만**(depth 탭=원본
  프레임만, cloud 탭=역투영만). 세션과 공존 불가(안내 표시, 종료 시 자동
  복귀).

<a id="d-evening"></a>
### 8/14 저녁 추가분 — 수집 흐름 다듬기

- **자동정렬 이탈 중단**: 정렬이 리더를 당기는 동안에도 매 틱 오차를 감시,
  GATE_RAD 밖으로 벗어나면 홀드를 풀고 중단(모터가 사람 손과 싸우지 않게).
  범위에 다시 들어오면 자동 재시도. 진입 시 범위 조건과 함께 게이트 구간
  모터 보호가 양쪽에서 걸린다.
- **카메라 최대화 (최종안)**: 두 카메라는 항상 좌우 배치를 유지하고, "보기"
  콤보(나란히/Agent 최대/Wrist 최대) 또는 뷰 더블클릭으로 **비율만
  88/12 로** 바꾼다. 겹침(PiP) 없음, 경계는 드래그로 미세 조절. (중간에
  겹침 방식으로 세 번 갔다가 사용자 피드백으로 좌우 비율로 확정 —
  `bb49270`→`a642cd0` 이력이 그 시행착오.)
- **리셋 대기 규칙 변경**: 시간이 지나도 저절로 끝나지 않는다. 물체를 놓고
  **"리셋 완료 — 계속 (Enter)"** 를 눌러야 게이트로 진행. 상태줄은 경과
  시간을 표시하고, Configure 의 "리셋 대기(s)" 입력은 (미사용) 비활성.
- **크롭 가이드 정리**: Point Cloud/Depth 뷰는 학습 프레이밍과 무관하므로
  정사각 크롭 음영을 끔.
- **노드 인디케이터**: 세션 장애 신호로만 갱신되어 "세션 연결됨 + 노드 -"
  로 보이던 표시 버그 → 시작 중(주황)→정상(초록)→"-"(종료)로 실제 상태
  추적. ("로봇이 연결 안 됐는데 연결된다"는 혼란의 원인이기도 했다.)
- **실패만 선택 버그**: 상태 컬럼이 legacy 는 "실패", scene 은 `failed`
  원문이라 scene 실패가 선택되지 않았다 → 두 표기 모두 매칭.

### scene 에피소드 편집 허용 — 삭제·트림 (8/14 밤)

실패·튀는 궤적을 HDF5 에서 지워 큐레이션하겠다는 결정으로 "scene 에피소드
불변" 가드레일을 완화했다. 규칙:

- **삭제** (Dataset "선택한 에피소드 삭제" / Dataset 메뉴 "에피소드 삭제" /
  Analysis 순위표): legacy 는 예전처럼 번호를 다시 매기고, **scene 은 번호를
  그대로 두고(빈자리 허용) 지운 uid 를 metadata `deleted_uids` 툼스톤에
  남긴다** → 같은 slot 의 다음 에피소드는 지운 E번호를 건너뛴다(uid 재사용
  금지 — 지운 것이 이미 Hub 에 있을 수 있다). 세션이 파일을 쥐고 있으면 saver
  경유(`SceneWriter.delete_episode`), 아니면 직접(`delete_scene_episodes`).
  파일 크기는 재압축 전까지 안 줄어든다. `check_scene_file.py` 가 툼스톤
  재사용을 잡는다.
- **트림** (Trim 탭): scene 에피소드도 끝 다듬기 가능 — 프레임축 데이터셋만
  자르고 uid·번호·instruction 은 보존, 그리퍼 보존/최소 20프레임 규칙 동일.
- **파일 삭제** (Dataset 메뉴): 양포맷 동일, 수집 중 파일·작업 중(재압축 등)
  차단, 되돌릴 수 없음 경고. 변경 없음(점검만).

## 4. 사용 지침

**일상 수집 흐름**
1. 아이콘 실행 → Configure 에서 계획(pilot.json)·scene 선택 → "계획 문장"
   드롭다운으로 시작 문장 선택(자동으로 slot ID 매칭) → 수집자 확인 → 연결.
2. 게이트: 리더를 팔로워에 대충 맞추면(0.5rad) 자동 정렬이 발동하고 Start 가
   열린다. Space=시작.
3. 기록 → Space(성공)/Esc(실패) 저장 → 리셋: 물체를 되돌린 뒤 **"리셋 완료 —
   계속" 버튼(Enter)** 을 눌러야 다음으로 진행(자동 종료 없음, 화면은 살아
   있음). 문장 전환은 Collect 의 "계획 slot" 드롭다운 + "slot 적용".
   파지 장면을 크게 보려면 Live 의 "보기" 콤보나 화면 더블클릭으로 한쪽
   카메라를 최대화(반대쪽은 좌우 배치 그대로 작게).
4. 새 문장이 필요하면 ✎ 로 계획에 먼저 추가. 새 scene 은 "새 Scene 구성 →
   추천 받기"로 배치를 받는 것을 권장.
5. 진행 상황은 Statistics 진행률에서, 검수는 Gallery/HDF5 뷰어/실로봇 재생으로.

**depth 를 켤 때**: Settings → 데이터셋 구조 → depth 체크(우선 wrist 만 권장)
→ 다음 세션부터 적용. 켜기 전 `python scripts/check_cameras.py` 로 USB 확인.
기록 확인은 HDF5 뷰어에서 `obs/*_depth` 미리보기.
