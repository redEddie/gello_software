## 도메인 모듈의 모양

    # apps/workspace/domains/<이름>.py
    class <이름>Ops:
        """한 줄 설명."""
        def __init__(self, win) -> None:
            self.win = win

        def on_something(self) -> None:
            ...

`WorkspaceWindow.__init__` 에서 위젯을 만들기 **전에** 만듭니다:

    self.<속성> = <이름>Ops(self)

옮긴 메서드 안에서는:

- `self.<위젯이나 상태>` -> `self.win.<...>`
- 같은 도메인 안의 다른 메서드 호출 -> `self.<메서드>()` 그대로
- 다른 도메인이나 창에 남은 메서드 호출 -> `self.win.<...>()`

메서드 이름의 앞 밑줄은 뗍니다 (`_on_delete_selected` -> `on_delete_selected`).
빌더·페이지의 `.connect(win._on_delete_selected)` 도 같이 고칩니다.

  `self.win.<위젯>` 으로 읽습니다.
